# Silent Lens

**Твои фото. Твои данные. Твоя приватность.**

Локальное десктопное приложение для Windows 10/11, которое показывает и удаляет
метаданные из фотографий. Работает полностью офлайн — без облака, без аккаунтов,
без телеметрии.

## Возможности

- 📷 **Просмотр метаданных** — EXIF, XMP, IPTC, GPS-координаты
- 🗺 **Карта GPS** — встроенная через OpenStreetMap
- 🧹 **Удаление метаданных** — три режима:
  - Только GPS
  - Всё, кроме даты
  - Все метаданные
- 📦 **Пакетная обработка** — все файлы из списка, с прогрессом и отменой
- 🛡 **Сохранение оригиналов** — в подпапку `_Original`
- 🖼 **Поддержка форматов** — JPEG, PNG, WebP (запись); HEIC, RAW, TIFF (только чтение)
- 🔎 **Авто-определение формата** по сигнатуре файла (magic bytes)
- 🎨 **Тёмная тема** — единственная и окончательная
- 🌍 **Русский интерфейс**
- 🖱 **Drag & Drop** файлов и папок в окно
- 📤 **Экспорт метаданных** в TXT и JSON
- 📦 **Экспорт оригиналов** в ZIP-архив
- ⚖ **Сравнение «до/после»** удаления метаданных
- 🔄 **Проверка обновлений** через GitHub Releases

## Установка

1. Скачай `SilentLens_v1.0.0.zip` из [последнего релиза](../../releases/latest).
2. Распакуй в любую папку.
3. Запусти `SilentLens.exe`.

Приложение **не требует** установки .NET — всё вшито в один файл.

## Сборка из исходников

```bash
git clone https://github.com/Boleznen/SilentLens.git
cd SilentLens
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

## Готовый SilentLens.exe появится в bin\Release\net8.0-windows\win-x64\publish\.
Использование

    Файл → Добавить файлы (или Добавить папку, или перетащи фото в окно).

    Клик по файлу — справа увидишь все его метаданные.

    Выбери действие:

        Стереть GPS — только координаты.

        Оставить только дату — всё, кроме даты съёмки.

        Стереть всё — все метаданные.

        Применить ко всем — пакетная обработка всех файлов.

Оригиналы сохраняются в подпапку _Original рядом с исходным файлом.
Горячие клавиши
Клавиша	Действие
Ctrl+O	Добавить файлы
Ctrl+D	Удалить метаданные из выбранного
Ctrl+Shift+D	Удалить метаданные из всех
Ctrl+F	Поиск по списку
F5	Обновить метаданные
Delete	Убрать из списка
Приватность

Silent Lens никогда не отправляет данные в интернет:

    Никакой телеметрии.

    Никаких аккаунтов.

    Никаких аналитических сервисов.

    Сетевой доступ — только для проверки обновлений (опционально) и загрузки карт OpenStreetMap (только при открытии карты GPS).
